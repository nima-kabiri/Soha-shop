# Soha Luxury Shop 🌟

فروشگاه اینترنتی با تبدیل ارز خودکار و اسکرپر محصولات از سایت‌های اروپایی.

## 📁 ساختار پروژه

```
soha-shop/
├── backend/
│   ├── server.js              # سرور اصلی + زمان‌بندی خودکار (cron)
│   ├── services/
│   │   ├── currency.js        # دریافت نرخ ارز روزانه
│   │   └── scraper.js         # اسکرپر محصولات (Playwright)
│   ├── routes/api.js          # API endpoints
│   └── db/database.js         # دیتابیس SQLite
├── frontend/
│   ├── index.html
│   ├── css/style.css
│   └── js/app.js
└── package.json
```

## 🚀 راه‌اندازی روی سیستم شخصی (تست محلی)

### پیش‌نیاز: Node.js نسخه ۱۸ یا بالاتر
از سایت [nodejs.org](https://nodejs.org) دانلود کنید.

### مراحل:

```bash
# ۱. ورود به پوشه پروژه
cd soha-shop

# ۲. نصب وابستگی‌ها
npm install

# ۳. نصب مرورگر مورد نیاز Playwright (برای اسکرپینگ)
npx playwright install chromium

# ۴. کپی فایل تنظیمات
cp .env.example .env
```

### ۵. تنظیم کلید API نرخ ارز (رایگان)
1. به [exchangerate-api.com](https://app.exchangerate-api.com/sign-up) بروید و رایگان ثبت‌نام کنید
2. کلید API که می‌دهند را در فایل `.env` جای `your_api_key_here` بگذارید

### ۶. اجرای پروژه

```bash
# اجرای سرور (فرانت + بک‌اند با هم)
npm start

# در یک ترمینال جدا، برای تست دستی اسکرپر:
npm run scrape

# برای تست دستی آپدیت نرخ ارز:
npm run update-rates
```

حالا در مرورگر بروید به: `http://localhost:3000`

### 🔑 ورود به پنل مدیریت
پنل ادمین در آدرس `http://localhost:3000/admin` در دسترسه.

اولین بار که سرور رو اجرا کنید، یک کاربر ادمین پیش‌فرض به‌صورت خودکار ساخته می‌شه و اطلاعاتش توی ترمینال چاپ می‌شه:
```
نام کاربری: admin
رمز عبور:   ChangeMe123!
```
⚠️ **حتماً بلافاصله بعد از اولین ورود، از بخش «تنظیمات → تغییر رمز عبور» این رمز رو عوض کنید.**

**امکانات پنل ادمین:**
- 📊 داشبورد: تعداد محصولات، مشتریان، سفارش‌ها، درآمد کل، نمودار ۷ روز اخیر، نرخ ارز لحظه‌ای
- 🛍️ مدیریت محصولات: مشاهده و حذف محصولات اسکرپ‌شده + وارد کردن محصول از ترندیول با لینک (عکس‌های گالری خودکار دانلود و روی هاست خودمان ذخیره می‌شوند، نه لینک مستقیم به ترندیول)
- 📦 مدیریت سفارش‌ها: تغییر وضعیت سفارش (در انتظار → تایید → ارسال → تحویل)
- 👥 مدیریت مشتریان: لیست مشتریان با تعداد و مجموع خریدشون
- ⚙️ تنظیمات: تغییر ضریب سود، هزینه ارسال، نرخ دلار به تومان — همه بدون نیاز به دست زدن به کد

## ☁️ دیپلوی روی سرور (برای اجرای دائمی و خودکار)

چون نیاز به **اجرای روزانه خودکار** (Cron) دارید، بهترین گزینه‌های ارزون/رایگان:

### گزینه ۱: Railway.app (پیشنهاد اصلی)
- رایگان تا ۵ دلار اعتبار ماهانه، بعد پرداختی ($۵-۱۰ ماهانه برای این پروژه)
- پشتیبانی کامل از Playwright و اجرای مداوم سرور
- مراحل:
  1. حساب در [railway.app](https://railway.app) بسازید
  2. پروژه را روی GitHub آپلود کنید (مرحله بعد توضیح می‌دم)
  3. در Railway گزینه "Deploy from GitHub" را بزنید
  4. متغیرهای `.env` را در بخش Variables وارد کنید

### گزینه ۲: Render.com
- مشابه Railway، پلن رایگان محدودتر ولی برای شروع مناسب است

### گزینه ۳: یک VPS ساده (مثل Hetzner یا آروان‌کلود ایرانی)
- کنترل کامل، حدود ۵-۱۰ دلار ماهانه
- نیاز به کمی کار دستی بیشتر (نصب Node.js، PM2 برای اجرای دائم)

**نکته:** چون احتمالاً به بعضی سایت‌های اروپایی از IP ایران دسترسی محدود است، سرور خارج از ایران (مثل Railway/Render/VPS اروپایی) گزینه بهتریه.

## ⚠️ نکات فنی مهم

1. **selectorهای اسکرپر نمونه‌ان** — باید با بازرسی واقعی صفحه هر سایت (کلیک راست → Inspect) دقیق تنظیم بشن، چون هر سایت ساختار متفاوتی داره. همین قانون برای `backend/services/trendyolImporter.js` هم صدق می‌کنه.
2. **محدودیت نرخ ارز رایگان**: پلن رایگان exchangerate-api ماهی ۱۵۰۰ درخواست می‌ده که برای آپدیت هر ۶ ساعت کافیه.
3. **نرخ تومان دستی**: چون ریال ایران در بازار جهانی نیست، این نرخ رو باید یا دستی آپدیت کنید یا از یک منبع داخلی (مثل tgju.org) بگیرید.
